# 외부 라벨 (평가 모드, SPEC 9.11)

라벨은 **지표 바깥에서** 온다(순환 논리 금지, SPEC 6.3). 지표는 라벨을 얼마나 예측하는지로 검증한다.

## 1. CDC PLACES (자동, 미국 지역)

- 2025 release 트랙트 조유병률(%) — `places_obesity`, `places_depression`, `places_lpa`(여가 신체활동 없음), `places_mhlth`(정신건강 나쁜 날 14일 이상), `places_bphigh`, `places_diabetes`, `places_phlth`.
- 셀 중심이 든 트랙트 값을 셀에 붙이고, 표본 권역에서는 **땅 면적 가중 평균**. 표본을 찍으면 표에 바로 나온다.
- 모델 추정치이며 인구 특성(나이·소득)에 크게 좌우된다. 횡단 비교 = 증거 강도 최하(SPEC 6.1).

## 2. 관찰·설문 CSV (라이브러리 → "라벨 CSV 불러오기")

머리글이 있는 CSV. 표본을 찾는 열 하나와 숫자 열들:

```csv
sample_id,people_count,stay_share,seats_per_100m
s_20261010_001,48,0.31,6
s_20261010_002,12,0.10,0
```

또는 좌표로(가장 가까운 표본 지점에서 150 m 안):

```csv
lon,lat,people_count
-73.9712,40.7831,48
```

- 숫자 열은 표본의 `labels.csv_<열 이름>`이 되고(소문자, 기호는 `_`), 비교 화면 스트립 차트에 나온다.
- 숫자가 아닌 값은 비워진다("데이터 없음"). 맞는 표본이 없는 줄은 건너뛰고 개수를 알려 준다.
- SOPARC·겔의 공공생활 조사처럼 **같은 프로토콜**로 모은 값만 같은 열에 넣는다.

## 3. 쌍대 비교 설문 결과 (형식만, 1차 범위에서 설문 도구는 만들지 않음)

이미지 출처(유료 API·약관) 문제로 설문 도구는 만들지 않았다. 다른 도구로 수행한 결과를 이 형식으로 불러온다:

```csv
sample_a,sample_b,question,winner
s_20261010_001,s_20261010_002,safety,a
s_20261010_001,s_20261010_003,lively,tie
```

- `winner`: `a` / `b` / `tie`. `question`이 없으면 `overall`.
- 표본마다 질문별 **승률**(이긴 횟수 + 무승부 0.5 ÷ 비교 횟수)을 `labels.pairwise_<question>`로 붙인다.
- 승률은 상대가 누구였는지를 보정하지 않는다(Bradley-Terry 등은 후속 과제).
