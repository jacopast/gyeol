# 결 (Gyeol)

공원 접근성에서 도시 공공공간의 결까지 — 같은 총 면적의 공공공간을 크게 모을지 작게 흩을지, **어떤 조건에서** 어느 쪽이 나은지를 보여주는 도구. 결론은 내리지 않는다.

- 명세: [SPEC.md](SPEC.md) · 계획: [PLAN.md](PLAN.md) · 결정: [DECISIONS.md](DECISIONS.md) · 가설: [HYPOTHESES.md](HYPOTHESES.md) · 지표: [METRICS.md](METRICS.md)
- 1차 지역은 맨해튼. 구조는 전 세계 도시용 (`config/regions/<id>.yaml` + 데이터 어댑터).

작업 중. 실행 방법·데이터 출처·한계는 M9에서 채운다.
